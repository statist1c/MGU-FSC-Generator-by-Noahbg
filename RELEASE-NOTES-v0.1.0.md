# v0.1.0 — Initial Android port

Original project: **Noahbg's mgu-apps FSC generator**. This Android application
ports the original generation and verification behavior; it is **not tested yet
on a real vehicle or head unit**.

- 34 application and ID7 Live Maps presets, custom IDs/indexes and VIN validation.
- Native RSA-2048 signing and strict verification using the public FSC Patch key.
- Android file picker import/export with saved-file readback verification.
- Dark/light/system rounded-card interface and original MGU FSC certificate icon.
- GitHub update checker for statist1c/MGU-FSC-Generator-by-Noahbg, verified APK
  downloads and user-controlled Android installation.
- Original author credits, MIT license and build-tool notices retained.

Requires Android 8.0 or newer. APK name: **MGU FSC Generator by Noahbg.apk**.
See `VALIDATION.md` for local checks and limitations.
